This repository compiles learning materials from the School of Chemistry at Xiamen University (XMU). If any content infringes on copyrights, please contact me for removal.

I hope this proves helpful to you. Contributions via Pull Requests are also welcome to supplement the materials.

## Usage Instructions

Due to the large size of the `.git` directory, it is recommended to use `--depth 1` when running `clone` to skip tracking previous versions, saving time and storage space.
You can also directly download the ZIP archive or grab specific files as needed.
